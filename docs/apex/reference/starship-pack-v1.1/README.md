# MASS EFFECT — DEFINITIVE STARSHIP REFERENCE PACK (V1)

Built for Mass Effect: Apex / Reaper War Simulator. Date: 6 November 2026.

## Start here
Open `index.html` in a browser. It is an interactive, searchable ship design catalog with curated visual links. The **gallery previews require internet** and may be blocked by third-party hosts; the original creator links are the stable fallback.

## Files
- `index.html` — browse ships, geometry confidence, images, source links, and modelling directions.
- `ship_registry.json` — importable canonical-vs-Apex ship registry with source provenance, scale flags and mesh priorities.
- `ship_registry.csv` — spreadsheet-friendly version.
- `visual_references.json` — vetted image/page URL list; external image URLs may expire.
- `source_index.csv` — all cited primary and secondary source pages.
- `DESIGN_BIBLE.md` — enforceable geometry, materials, weapons, movement and performance rules.
- `CAPTURE_PROTOCOL.md` — how to create definitive 6-view turnarounds from legitimate game captures.
- `CODEX_BUILD_BRIEF.md` — pasteable development instructions.
- `APEX_EXPANSION.md` — AU-only and original ship designs.

## Truth hierarchy
A. **On-screen Mass Effect trilogy model and original game artist assets**: geometry anchor.
B. **Published official concept art**: authorial direction, but may differ from shipped model.
C. **Licensed replica based on game asset**: corroborating reference.
D. **Fan-reconstructed ortho or mod mesh**: helpful template, must verify with A/B/C.
E. **Fan fleet charts, guessed dimensions, named classes from fandom**: never automatically canon.
F. **Apex original**: deliberately separate AU design.

Critical: A *canon ship name* is not proof of an *official exterior model*. A 3D model can be geometrically authentic while fan size estimates remain uncertain.

## Copyright / permissions
This pack contains original notes, data and links, not copied game models or redistributed external images. Obtain permission and check licenses for any third-party 3D meshes or textures you incorporate. Capturing your own reference screenshots is distinct from distributing extracted game models.

## Scope
Trilogy-era Milky Way (primarily 2183–2186) + Mass Effect: Apex AU. Andromeda designs should live in a separate expansion; do not mix in as trilogy-era stock assets.
