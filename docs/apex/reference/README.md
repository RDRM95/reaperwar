# Mass Effect Apex reference pack

Prepared 29 October 2026.

## Files

- **APEX_Fleet_Reference.md** — sourced canon anchors, ship roles and named hulls, technology, full proposed Sol roster, Reaper campaign accounting, Valkyrie, Titan/HADES, Cerberus, drive sacrifices and simulator rules.
- **APEX_Montage_Prompts.md** — a separate production guide with 24 shot cards, reusable editing and motion prompts, character direction, optional dialogue, captions, music cue plan and Resolve workflow.
- **apex_simulator_data.json** — machine-readable reference data, including evidence labels, hull and weapon profiles, counts, presets and sensitivity settings.
- **validation_results.json** — completed arithmetic, reference and isolated shield-model checks, with the limits of those checks stated.

## Current continuity

Shepard Prime never dies. Javik is recovered in 2183. Saren, Nihlus and Jenkins survive. Mordin completes an earlier cure. Quarians and geth cooperate. The unindoctrinated Illusive Man commits Cerberus to destroying Reaper forces. There is no Crucible or galaxy-wide shutdown. EDI and the geth survive.

The Alliance has 15,292 total hulls, including 13,292 warships and 2,000 support ships. Sol receives 38,420 coalition warships plus 612 fixed heavy platforms. The proposed Black Fleet supplies the 420 warships absent from the old chart's arithmetic.

The inherited Reaper invasion preset has 2,000 capitals and 40,000 destroyers, plus 11,000 specialist vessels. These are AU assumptions. The Sol-only scenario starts with 480 capitals and 12,000 destroyers, after explicitly accounted campaign losses and deployments elsewhere. This regional allocation is a new proposal.

## Using the data

Canon fields and simulation fields are separate. Unknown canonical values remain null. A named canonical ship can use an explicitly invented numerical model; that does not turn the model into an official specification.

The dataset is not a drop-in integration for an unspecified application. Adapt its IDs and fields to your simulator. Preserve its source and evidence metadata when importing it. Do not map war-asset points to ship counts.

The core Valkyrie uses a large but limited accelerator and coordinated Thanix fire. The legacy high-power Nova is separate and disabled in the core preset. Drive sacrifices are explicitly experimental AU events with finite attempts and interruption windows.

The included shield trial has no return fire or manoeuvre. It confirms the chosen loading behaviour, not a predicted battle result. No full fleet battle, campaign forecast, industrial throughput proof or victory probability is claimed.

## Building the montage

Start with the ten-shot assembly in the montage guide. Preserve original source faces and backgrounds wherever possible, insert one clear alternate-history detail, and animate only the minimum needed. The exact music edit was not supplied; the guide therefore uses musical landmarks instead of timestamps.

Use the final ordinary crew moment to carry the emotional reward. Credit the actual footage and music sources you use. The guide includes current official publication references.
